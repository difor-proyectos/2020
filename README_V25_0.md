# DIFOR V25.0 — Panel Control Productivo

Base V24.9 preservada. Cambios concentrados en Panel Control:

- Tareas editables, eliminables, marcables/desmarcables y reordenables.
- Prioridad Alta / Media / Baja y fecha de referencia.
- Orden persistente por Día / Semana / Mes.
- Apuntes diarios y mensuales con escritura directa, botón Guardar y autoguardado.
- Accesos rápidos editables y ordenables desde el Panel.
- Resumen de actividad de hoy y pulso mensual usando registros existentes.
- Alertas visuales para tareas atrasadas.
- Diseño responsive para PC, tablet y móvil.
- Cache PWA actualizado a difor-v25-0.
