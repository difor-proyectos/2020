# DIFOR V25.1 — Panel Operativo + Dashboard

## Cambios principales
- Panel Control separado del análisis: ahora funciona como centro operativo diario.
- Parte superior del Panel: Accesos rápidos + Recordatorios.
- Recordatorios: crear, editar, completar y eliminar desde el Panel.
- Actividades: se mantienen tareas Día / Semana / Mes editables y ordenables.
- Apuntes del día y mes con autoguardado.
- Nuevo módulo Dashboard en la navegación principal.
- Dashboard mensual con gestiones totales, prospectos, ventas, conversión, actividad del día, embudo y resumen por módulo.
- Acceso directo Panel ↔ Dashboard.
- Reportería disponible desde Dashboard.
- Base de datos y módulos comerciales existentes preservados.
- Cache PWA actualizado a difor-v25-1.
