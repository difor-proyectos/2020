# DIFOR V26.0 · Sales Workspace

Versión completa basada en V25.5, enfocada en productividad comercial y experiencia de uso.

## Principios V26
- Inicio se mantiene como portada comercial para usar frente al cliente: no muestra KPI, prospectos, BK ni información interna.
- Black/White Executive: superficies neutrales, menor saturación, mejor jerarquía y menos scroll.
- Prospectos CRM se transforma en panel principal de conversión con etapas, score, próxima acción, BK, WhatsApp, llamada, cotización, publicidad, visita y cartera futura.
- Sala de Venta evoluciona a Showroom con afiches compactos diferenciados por marca sobre la base visual DIFOR.
- Asistente Multimarca filtra vehículos de Sala según presupuesto, transmisión, tracción y prioridad usando únicamente datos cargados en DIFOR.
- Persistencia compatible con la base existente; los nuevos campos CRM se agregan a los registros actuales sin migración destructiva.

## Objetivo operativo
Todo prospecto activo debe tener una próxima acción. El flujo de referencia es:
Ingreso → Contacto → BK → Propuesta → Visita → Negociación → Venta, con salida a Seguimiento futuro cuando no se concreta.
