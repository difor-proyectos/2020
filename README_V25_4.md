# DIFOR V25.4

Versión completa sobre V25.3.

## Mejoras principales
- Dashboard con filtros por mes, rango de días y año completo.
- Evolución mes a mes, comparación contra período anterior y conversiones separadas.
- PDF de cotización 100% editable dentro de la web antes de imprimir/guardar.
- Nuevo icono de tarjeta digital y topbar optimizada.
- Widget Rápido web/PWA para tareas, recordatorios, apuntes e indicadores.
- Reportería orientada a DATA_MASTER y Hoja Maestra V25.4 profesional.

## Widgets del sistema operativo
La PWA ofrece un modo Widget Rápido y accesos directos instalables. Widgets nativos de Android/Windows requieren un paquete nativo adicional (APK/MSIX) y no se simulan desde una PWA estándar.
